# NASA data and resources used by Black Fox

Every NASA source the project uses: the 24 PSI combustion investigations, the NASA Technical Reports Server papers behind the physics and the data, and the standards, fact sheets and reports behind the other numbers. The site links each number to its source; this page lists them all in one place.

Live project: https://blackfoxhackathon.hu
